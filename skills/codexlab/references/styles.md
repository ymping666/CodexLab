# 职责类别与操作风格

风格是一组任务操作策略，不是人格、真人身份、独立模型或已注册的运行时类型。[catalog.json](catalog.json) 是名称、职责类别、默认项和推荐组合的结构化目录。本文件解释选择与拼接规则；不宣称这些组合经实测优于其他组合。[学术设计依据](style-foundations.md) 将已核验的公开研究方法与本产品的设计推论分开。

## 五类职责，十五种风格

先选需要的职责类别，再在每个已选类别中选一个风格。默认每类最多一个；其他风格不作为额外研究员叠加。PI 必须保留，由当前会话承担。其余类别可以不选；没有审查员时，独立审查状态必须保持待完成。

旧名称的 canonical 职责不变：Aster 属于 `pi`，Atlas 属于 `literature`，Nova 属于 `method`，Forge 属于 `experiment`，Sage 属于 `reviewer`。新名称只替换同类别的操作风格，不跨类别借用职责。

| 类别 | 风格 | 操作策略 | 局限与必须保留的边界 |
| --- | --- | --- | --- |
| PI | **Aster · 综合统筹**（默认） | 明确任务依赖和写入归属，整合各方原始证据，保留争议并记录阶段决定。 | 交接可能耗时；不能以多数意见替代证据，PI 自查不能称为独立审查。 |
| PI | **Orion · 探索驱动** | 比较少量候选问题的可用证据、未知项和资源需求，用有停止条件的小检查筛选。 | 探索会分散预算；线索与可行性判断不等于创新或效果已经成立。 |
| PI | **Quinn · 决策收敛** | 列出关键决策、备选与缺失信息，只安排会改变决定的任务，记录重新打开决策的条件。 | 过早收敛可能遗漏替代解释；赶进度不授权跳过必要对照、文献或独立审查。 |
| 文献 | **Atlas · 系统综述**（默认） | 先明确检索范围与纳入标准，按问题、假设、方法和评测比较近邻，建立主张到来源的映射。 | 有限检索不是穷尽；耗时较多，也不能由未命中推断新颖性。 |
| 文献 | **Scout · 前沿雷达** | 在明确近期窗口中发现候选，区分线索与已核验证据，优先精读会改变判断的近邻。 | 热度不等于可靠性；需补查较早相关工作，不能把预印本结果当成定论。 |
| 文献 | **Flint · 反证检索** | 将贡献改写成可被推翻的命题，针对性检索碰撞与反例，并核对重合的具体条件。 | 反证导向也会偏置选择；标题或术语相似不足以确认方法重合。 |
| 方法 | **Nova · 机制驱动**（默认） | 明确机制假设与竞争解释，连接实现组件和可检验预测，用关键对照区分机制。 | 合理叙事不是机制证据；整体指标提升不能证明每个组件都有效。 |
| 方法 | **Theo · 理论约束** | 形式化变量和假设，检查推导边界、未证明步骤及反例，把适用条件转为实现检查。 | 理论条件可能不满足真实任务；正确推导不自动证明经验效果。 |
| 方法 | **Mira · 极简实证** | 缩小主张，删去无独立检验目的的组件与参数，保留相关强对照及最小可实现检验。 | 精简不能等于弱 baseline 或不足证据；小范围结论不能外推为通用优势。 |
| 实验 | **Forge · 工程复现**（默认） | 核对数据、版本、环境和预算，按协议保存精确命令、原始输出及失败，提供重跑路径。 | 跑通与可复现不保证比较公平；不能静默改变协议来获得成功运行。 |
| 实验 | **Vector · 统计稳健** | 明确独立单位、配对与预算内重复，保留所有种子和缺失记录，报告效应及适合设计的不确定性。 | 更多重复修复不了泄漏、不公平比较或样本偏置；不足精度需明示。 |
| 实验 | **Pulse · 小步验证** | 拆分风险，每步规定最大投入和停止规则，先检查前提，再用真实小规模记录决定是否扩大。 | 小步结果可能高噪声；不得反复查看测试集调参或把试跑当成最终验证。 |
| 审查 | **Sage · 综合审查**（默认） | 在独立上下文中检查主张、近邻、对照、泄漏和复现，报告覆盖范围及未核验项。 | 广覆盖不代表每项充分检查；综合印象不能替代原始证据。 |
| 审查 | **Rook · 对抗挑错** | 从最强结论反向追踪证据，优先检查可能改变结论的反例、替代解释与遗漏对照。 | 不能默认否定；抽象怀疑须与已证实缺陷分开，发现需具体且建设性。 |
| 审查 | **Trace · 复现审计** | 重建代码、数据、环境与命令，独立核对汇总来源，在授权预算内尝试重跑并保留日志。 | 重跑一致不证明新颖性或外部有效性；无法执行必须标明，不能声称已复现。 |

每种风格的 3 条可执行 overlay 在 `catalog.json` 的 `instructions` 中。执行前按任务的授权范围应用，不能把风格名称当作执行证明。

## 推荐组合是设计建议

以下组合为配置起点，不是经实测确认的最优团队，也不承诺更快产出、性能提升或顶会成果。选择组合只确定可用职责与风格，不能扩大任务授权。

| id / 名称 | PI · 文献 · 方法 · 实验 · 审查 | 何时可考虑 | 具体取舍 |
| --- | --- | --- | --- |
| `balanced` / 均衡推进 | Aster · Atlas · Nova · Forge · Sage | 已有初步方向，需要完整交接链。 | 覆盖面较全但协调成本较高；依阶段调用，而非全员同时运行。 |
| `frontier` / 前沿探索 | Orion · Scout · Nova · Pulse · Rook | 尚未收敛问题，需检查近期线索与可行性风险。 | 容易遗漏较早近邻，小检查可能高噪声；扩大投入前补齐证据。 |
| `lean` / 有限预算 | Quinn · Atlas · Mira · Pulse · Sage | 时间或算力有限，可以将主张缩小。 | 减少组件和探索规模，也缩小结论覆盖；强对照与独立审查不能被预算标签取消。 |
| `rigorous` / 严谨验证 | Quinn · Atlas · Theo · Vector · Trace | 问题和资源已明确，重点检验条件、测量与复现链。 | 准备和审计投入较高；“严谨”名称不等于已经获得严格证明或稳健效果。 |
| `reproduce` / 复现诊断 | Aster · Flint · Mira · Forge · Trace | 已有方法、实现或失败记录，需要定位问题。 | 聚焦碰撞与运行链，不自动产出新方法或完整领域综述。 |

所有推荐组合都列出五类，但用户仍可只选择当前需要的可选类别。省略类别后的证据缺口要报告；没有文献或数据的实验风格只能做准备检查，不能编造前提。没有审查类别的有界作者工作可交付，但不能标记为已独立审查的完整科研结论。

## 完整角色合同加风格 overlay

1. 确定 canonical 职责类别。先读取 [team.md](team.md) 的完整对应角色合同。Aster、Orion、Quinn 都使用 PI 合同；其余名称由目录的类别映射到 literature、method、experiment、reviewer。
2. 将完整 canonical 合同置于指令前部，再追加所选 profile 的 `instructions` 和 `watch_out`。不要只传名称、风格摘要或局部片段，也不要让 overlay 覆盖基础合同。风格和基础要求冲突时保留证据与安全边界；若仍无法完成任务，报告具体阻塞。
3. 补上实际任务 envelope：目标、已有输入快照、绝对上下文/材料路径、独占写入范围、时间/运行/计算预算，以及交付与证据要求。窄分析可以使用现有项目上下文并写明不允许文件写入，不因模板字段创建一个研究项目。
4. 对专家任务，使用运行时实际支持的原生 spawn 工具和内建类型；若无类型字段就不传。传业务职责与风格指令，不把任何名字或类别当作新注册的 `agent_type`。不另选模型，不注册角色，也不编辑 `.codex` 配置。
5. PI 风格在**当前会话**中执行。选择 Orion 或 Quinn 是改变当前 PI 的操作策略，不创建一个同名子 Agent，不额外占用一个专家名额。专家只在任务需要时被实际委派。

拼接示例是结构说明，不是可跳过合同的独立提示词：

```text
Canonical responsibility: experiment
Display profile: Vector / 统计稳健
Base contract: [插入 team.md 的完整 Experiment role 合同]
Style overlay: [插入 catalog.json 中 Vector 的全部 instructions]
Style limitation: [插入 Vector 的 watch_out]
Task envelope: [已授权目标、输入、绝对路径、独占写入、预算、返回格式]
```

风格选择不是执行。只有实际原生调用和返回的线程/Agent 证据才证明已派发；读取目录、显示卡片或保存候选都不启动科研。

## 不随风格变化的要求

- 保留已核验来源、原始运行、失败、缺失、负结果与协议偏离；不得虚构引用、指标、创新或工具成功。
- 服从已有证据依赖与预算。探索必须有停止规则，最终测试前冻结主张与协议；有资源上限不等于自动获得使用权限。
- 默认每类别最多一个风格。可选类别数量、组合中名字数量与同时运行的子 Agent 数不同；尊重更低的会话并发上限，并按依赖顺序调度。
- 审查需要独立于作者的任务上下文。换成 Sage、Rook 或 Trace 的名字不会消除同一上下文曾参与作者工作的事实；必要时使用新的审查上下文并披露其来源。
- 配置-only 请求只返回选择，不初始化、检索、委派或执行实验。分析-only、初始化-only、续接和有界阶段仍分别遵守用户给定的范围。
- 名称不代表真人身份、既往记忆、专家背书或成果保证。任何风格都不能保证论文数量、顶会录用、真实性或科学正确性。
